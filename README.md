# Terminal Tycoon

A terminal-based startup company simulator built in Python.

## Features
- Hire employees
- Raise funding
- Manage burnout
- Random business events
- Save/load system
- Startup growth simulation

## How to Run

```bash
python main.py
```

## Preview

You start with:
- $5000
- 3 employees
- 0 users

Build the next billion-dollar startup.
